## 仓库中的数据流

```text
*.vert / *.frag
      │  #include
      ▼
*.glsl chunks ──→ Rspack dependency graph
      │
      ▼
export default "expanded shader source"
      │
      ▼
WebGL compile → link → draw
```

继续查看可复制的[原生 WebGL](/examples/webgl)、[Three.js](/examples/threejs) 和 [WebGPU / WGSL](/examples/webgpu) 示例。
